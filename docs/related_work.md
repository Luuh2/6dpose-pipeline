# 相关工作

本管线以 FoundationPose (CVPR 2024) 为核心做未知物体 6D 位姿追踪，其 `track_one` 为纯 RGB-D 局部优化、不含 mask 参数，纯单目下需额外观测引导；以 Depth Anything V3 从单张 RGB 估计度量深度替代真实深度（噪声大，需每帧估计+降噪）；以 TripoSR 做首帧单视图重建（背面缺失、形状矮胖），再以 Stream3D 流式多视图重建补全背面几何（覆盖 23%→36%，网格更贴合物体，但局部坐标系可能漂移，故引入本体坐标系固定）；以 XMem 时序传播首帧掩码替代周期重检测；以 COCO+深度平面验证为主力检测、YOLO-World 零样本仅作 fallback；最后以 SE(3) LIEKF 平滑融合位姿。
