# 相关工作

本管线以 FoundationPose (CVPR 2024) 为核心做未知物体 6D 位姿追踪：其 `track_one` 为纯 RGB-D 局部优化、不含 mask 参数，单目下需掩码质心/惯性主轴/bbox 等外观测引导，并以 SE(3) LIEKF 平滑。深度以 Depth Anything V3 从单帧估计度量深度替代真实深度（噪声大，需每帧估计+中值/双边降噪；实测其深度与真实 RealSense 深度追踪效果相当，均约 0.53-0.56 IoU）。网格以 TripoSR 首帧单视图重建为起点（背面缺失、形状矮胖），再以 Stream3D 流式多视图重建补全背面几何（需先有追踪位姿作为相机轨迹输入，故两遍：粗网格追踪→Stream3D 重建→再追踪），并引入本体坐标系固定防轴向漂移。掩码以 XMem 时序传播首帧掩码（SAM 分割）替代周期重检测；检测以 COCO+深度平面验证为主力、YOLO-World 零样本为 fallback；另评估过 SAM3 视频跟踪作掩码源（与 XMem 等价，未采用）。资源层面：模型串行加载，管线峰值显存由 FoundationPose 主导（720p 约 8.3GB），显存随分辨率平方下降，低配目标（3060 6GB）需 360p+降采样点。
