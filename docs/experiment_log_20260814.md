# 实验记录 2026-08-14

针对用户自摄视频的追踪问题（6D 框每 1 秒抖动、静物时绕垂直轴旋转），逐项排查修复：①定位 ~1Hz 抖动源于 CONFIDENCE_CHECK 硬编码 360p 裁剪导致 720p 视频 IoU 计算错误、每 30 帧误触发重注册，改为实际帧尺寸 + 重注册 SE(3) 平滑 + 连续低置信才触发（重注册 19→2 次）；②新增多帧检测，首帧目标不清晰时自动尝试后续帧（保温杯在 f76 才检出，此前误检 laptop）；③通过逐个禁用定制层定位静物旋转漂移根源为 LIEKF 速度模型在静物时累积偏差，静物模式速度强制归零后静态漂移 -18°→-5°（剩余为初始收敛，另试"静物旋转阻尼"方案无效已回退）；④在多视频验证 Stream3D 两遍流程（TripoSR 预追踪→Stream3D 重建→再追踪），鼠标视频贴合 82→11px、IoU 0.373→0.472，书 0.482、瓶子 0.582。最终形成当前最优管线（多帧检测 + Stream3D 两遍 + LIEKF 修复 + 重注册平滑），多物体 IoU 稳定 0.47~0.58。
