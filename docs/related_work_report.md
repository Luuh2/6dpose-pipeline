# 相关工作与技术报告：纯 RGB 6D 位姿追踪管线

## 1. 管线

借鉴 RGB-Track 闭环设计思路，改良搭建：
**YOLOv8-COCO（深度平面校验） + EfficientViT-SAM + XMem 时序掩码 + DepthAnythingV3 逐帧深度 + Stream3D 多视图重建 + 深度引导尺度对齐 + FoundationPose（掩码重锚定 + 本体坐标系固定） + SE(3) LIEKF 平滑 + 故障自动恢复**

要点：
- 检测：COCO+深度平面验证为主，多帧检测（首帧不清晰自动试后续帧）
- 掩码：XMem 时序传播，消除周期重检测轮廓跳变
- 网格：Stream3D 替代 TripoSR，补全背面几何（覆盖 23%→36%）
- 本体坐标：初始化固定长轴为朝向基准，禁止实时点云 PCA 重算轴向

## 2. 消融实验与瓶颈

基于 BOP-LMO 两组 2×2 对照（单帧初始化 / 长序列跟踪），发现：

1. **单目深度固定尺度偏差是主瓶颈**——数百毫米级位姿误差，可致初始化失败
2. **掩码质心约束仅适用于跟踪阶段**——初始化时 register 已用掩码划定搜索范围，质心修正是冗余，引入分割噪声
3. **高速运动下固定搜索范围跟不上**，周期重检测易轮廓跳变
4. **TripoSR 静态网格失真**——目标大幅旋转/遮挡后，网格偏差使跟踪陷入局部最优

## 3. 针对性改进

- **Stream3D 两遍**：TripoSR 预追踪 → Stream3D 重建 → 再追踪。贴合 82→11px，IoU 0.373→0.472
- **XMem 时序掩码**：覆盖率 34%→98%，丢失自动恢复
- **本体坐标系固定**：朝向误差 41.9°→5.9°，消除轴向翻转
- **初始化/跟踪分工**：初始化舍弃质心约束，仅跟踪启用重锚定
- **LIEKF 静物速度归零**：杜绝静止滚转漂移，高速信任当前帧
- **抖动修复**：重注册平滑 + 连续低置信才触发
