# 相关工作与技术报告：纯 RGB 6D 位姿追踪管线

## 1. 管线

借鉴 RGB-Track 闭环设计思路，改良搭建：
**YOLOv8-COCO（深度平面校验，多帧检测） + EfficientViT-SAM + XMem 时序掩码 + DepthAnythingV3 逐帧深度 + Stream3D 多视图重建 + 深度引导尺度对齐 + FoundationPose（掩码重锚定 + 本体坐标系固定） + SE(3) LIEKF 平滑 + 故障自动恢复**

要点：
- 检测：COCO+深度平面验证为主，多帧检测（首帧不清晰自动试 1/4、1/2、3/4、9/10 处帧）
- 掩码：XMem 时序传播（覆盖率 34%→98%，丢失自动恢复），消除周期重检测轮廓跳变
- 深度：DA3 逐帧度量深度；实测与真实 RealSense 深度追踪效果相当（IoU 0.563 vs 0.535，DA3 略优），非瓶颈；已知相机内参时应优先用标定 K（DA3 估计 K 可偏 1.7 倍，影响网格尺度）
- 网格：Stream3D 多视图重建替代 TripoSR，补全背面几何（覆盖 23%→36%）
- 本体坐标：初始化固定长轴为朝向基准，禁止实时点云 PCA 重算轴向
- 追踪：FoundationPose + 掩码质心/惯性主轴/bbox 引导 + LIEKF（静物速度归零、运动自适应）

## 2. 消融实验与瓶颈

基于 BOP-LMO 两组 2×2 对照（单帧初始化 / 长序列跟踪）及多视频实测，发现：
1. **单目深度尺度偏差曾为主瓶颈**——数百毫米级位姿误差可致初始化失败；经深度引导尺度对齐 + 每帧估计缓解，且 DA3 与真实深度对比表现相当，深度已非主要瓶颈
2. 掩码质心约束仅适用于跟踪阶段——初始化 register 已用掩码划定搜索范围，质心修正是冗余，引入分割噪声
3. 高速运动下固定搜索范围跟不上，周期重检测易轮廓跳变
4. TripoSR 静态网格失真——目标大幅旋转/遮挡后，网格偏差使跟踪陷入局部最优（Stream3D 改善）
5. **相机内参（K）估计可靠性**：DA3 估计 K（fx=554）与视频真值（fx=319.58）差 1.7 倍，影响网格尺度与投影；用真值 K 后 DA3 深度 IoU 0.553→0.563
6. **追踪对深度噪声敏感**：相同输入（mask/深度/K/网格几乎一致，仅 4-7mm fp16 噪声）多次运行可能落入不同位姿解，旋转差可达 180°——需固定 seed 保可复现，并加强对称歧义抑制

## 3. 针对性改进

- **Stream3D 两遍**：TripoSR 预追踪 → Stream3D 重建 → 再追踪。贴合 82→11px，IoU 0.373→0.472
  - 说明：Stream3D 输入是"已配准位姿的视图流"（图像+掩码+深度+相机轨迹），不输入 mesh；相机轨迹由第一轮追踪位姿取逆得到。第二轮 FP 必需：重建网格与追踪网格参考系不一致，直接复用第一轮 pose 贴合 52px vs 第二轮 11px
- **XMem 时序掩码**：覆盖率 34%→98%，丢失自动恢复
- **本体坐标系固定**：朝向误差 41.9°→5.9°，消除轴向翻转
- **初始化/跟踪分工**：初始化舍弃质心约束，仅跟踪启用重锚定
- **LIEKF 静物速度归零**：杜绝静止滚转漂移，高速信任当前帧
- **抖动修复**：重注册平滑 + 连续低置信才触发
- **SAM3 视频跟踪评估**：mask 与 XMem 高度一致（IoU 0.94-0.98），追踪结果等价（未采用，掩码非瓶颈）
